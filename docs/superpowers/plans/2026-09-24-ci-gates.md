### Task 5: Publish gating (verify job, dry-run, tag↔version assert, wasm installer)

**Files:**
- Modify: `.github/workflows/publish-crates.yml` (full rewrite, 27 → ~56 lines)
- Modify: `.github/workflows/publish-wasm.yml` (add verify job; replace installer)

- [ ] **Step 1: Rewrite `publish-crates.yml`** to:

```yaml
name: Publish crates to crates.io

# Releases Rust crates on version tags (v*). The wasm crate is published to
# npm by publish-wasm.yml instead. Requires the CARGO_REGISTRY_TOKEN secret.

on:
  push:
    tags:
      - "v*"

permissions:
  contents: read

jobs:
  verify:
    name: Verify
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
        with:
          components: rustfmt, clippy
      - uses: Swatinem/rust-cache@v2
      - name: Assert tag matches crate versions
        run: |
          tag_version="${GITHUB_REF_NAME#v}"
          meta="$(cargo metadata --no-deps --format-version 1)"
          status=0
          for crate in zsign-core zsign-rs zsign-cli; do
            version="$(jq -r --arg name "$crate" '.packages[] | select(.name == $name) | .version' <<<"$meta")"
            if [[ "$version" != "$tag_version" ]]; then
              echo "::error::$crate version $version does not match tag $GITHUB_REF_NAME"
              status=1
            fi
          done
          exit "$status"
      - name: Check formatting (all files)
        run: cargo fmt --all -- --check
      - name: Clippy (workspace, deny warnings)
        run: cargo clippy --workspace --all-targets -- -D warnings
      - name: Run tests
        run: cargo test --workspace

  publish:
    name: Publish
    needs: verify
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - uses: Swatinem/rust-cache@v2
      - name: Dry-run package zsign-core
        run: cargo publish -p zsign-core --dry-run
      - name: Publish zsign-core
        run: cargo publish -p zsign-core --token "${{ secrets.CARGO_REGISTRY_TOKEN }}"
      - name: Publish zsign-rs
        run: cargo publish -p zsign-rs --token "${{ secrets.CARGO_REGISTRY_TOKEN }}"
      - name: Publish zsign-cli
        run: cargo publish -p zsign-cli --token "${{ secrets.CARGO_REGISTRY_TOKEN }}"
```

name: examples/web

on:

  build:
    name: Build examples/web
